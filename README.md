```
https://wscjdsb666-creator.github.io/cg-football-club/
```

托管在 **GitHub Pages**（免费、全球可访问、自带 HTTPS）。仓库：
`https://github.com/wscjdsb666-creator/cg-football-club`

### 以后怎么更新（一条命令）

改完网站文件后运行：

```powershell
pwsh -File "E:\数字营销\cg-fc\tools\deploy-pages.ps1"
```

脚本会自动生成单文件离线版、提交、推送，约 1 分钟后线上自动更新。

### 离线演示版

`standalone.html` 是把 HTML、CSS、JavaScript 和所有图片打包在一起的**单文件版本**。
双击就能打开、断网也能看、可以直接发微信或邮件给别人（图片较多，文件约 1.5MB）。

## 怎么改（常见需求）

**改文案**：打开 `index.html`，直接搜索要改的字就能找到。
**改队色**：打开 `assets/css/styles.css` 最上面的 `:root`，改 `--navy-600`（蓝）和 `--red-500`（红）。
**换某个队员的头像**：先看 `assets/img/players/名单对照.md` 找到他的编号，
把自己的图片裁成正方形、命名为 `pNN.jpg` 覆盖进去即可（建议 240×240 以上）。
**改号码 / 位置 / 加人**：打开 `assets/js/main.js`，最上面的 `ROSTER` 数组里改，
每行是 `{ name:'名字', no:号码, pos:'位置' }`，位置只能填 门将 / 后卫 / 中场 / 前锋。
**改队史战报**：`index.html` 里搜「队史战报」，比赛条目就在下面。
**改奖项**：`index.html` 里搜「队内年度奖项」。

## 注意事项

- `.nojekyll` 文件必须保留，否则 GitHub Pages 会按旧规则处理页面。
- 队员头像来自球队群聊截图，只用于本队展示；如果哪位队员不希望头像公开，把他的头像文件换成别的图（或告诉队长撤下）即可。
- 队史战报、战绩与奖项是球队内部记录整理，不是职业联赛官方数据；页面上也写明了这一点。
- 队徽、队长插画、分享图均为本站原创。
